# Fraud Detection Analytics Dashboard

**An End-to-End Data Analytics Project using SQL, Python, and Power BI**

## Overview

This project analyzes procurement transaction data to identify potential fraud patterns, evaluate supplier risk, and monitor compliance. It combines SQL-based analysis, Python data processing, and an interactive Power BI dashboard to transform transaction data into actionable insights.

## Business Objectives

* Analyze procurement transactions and identify fraud indicators.
* Measure overall fraud cases and fraud percentage.
* Evaluate supplier risk based on flagged transactions.
* Examine fraud patterns across item categories and compliance status.
* Monitor monthly fraud trends and transaction pricing patterns.
* Provide transaction-level details for further investigation.

## Technology Stack

| Technology           | Purpose                                  |
| -------------------- | ---------------------------------------- |
| PostgreSQL / pgAdmin | Database querying and data exploration   |
| Python               | Data processing and exploratory analysis |
| Power BI             | Dashboard development and visualization  |
| Jupyter Notebook     | Python analysis workflow                 |

## Dashboard Highlights

* **Key Performance Indicators:** Total Transactions, Total Fraud Cases, Fraud Percentage, and High-Risk Suppliers.
* **Category Analysis:** Fraud distribution across procurement item categories.
* **Compliance Analysis:** Comparison of flagged transactions by compliance status.
* **Trend Analysis:** Monthly fraud trends over time.
* **Supplier Risk Analysis:** Top 10 suppliers ranked by fraud case count.
* **Price and Quantity Analysis:** Scatter plot exploring transaction patterns by fraud status.
* **Transaction Details:** Detailed records to support further investigation.

## Project Workflow

1. **Data Access:** Load procurement transaction data.
2. **SQL Analysis:** Query and aggregate transaction records.
3. **Python Analysis:** Process data and perform exploratory analysis.
4. **Visualization:** Develop an interactive Power BI dashboard.
5. **Insight Generation:** Examine fraud indicators, supplier patterns, and compliance trends.
